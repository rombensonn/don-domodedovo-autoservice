# Автосервис «Дон» - лендинг

Индустриальный одностраничный лендинг автосервиса на М-4 Дон.

## Что внутри

- `index.html` - статическая версия для GitHub Pages.
- `index.php` - PHP-версия с обработкой формы и сохранением заявок в `storage/leads.csv`.
- `assets/` - стили, JavaScript и сгенерированные тематические изображения.
- `privacy.html` / `privacy.php` - политика обработки данных.

## Важно про GitHub Pages

GitHub Pages открывает только статические файлы и не исполняет PHP. Поэтому публичная ссылка на GitHub Pages показывает статический рендер сайта. Для рабочей PHP-формы нужен хостинг с поддержкой PHP.
