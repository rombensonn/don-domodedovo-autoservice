Политика обработки данных

Настоящая политика описывает, какие данные передаются через форму записи на сайте автосервиса «Дон» и для чего они используются.

Какие данные собираются

Через форму могут быть переданы имя, телефон, выбранная услуга, сведения об автомобиле и комментарий клиента.

Цель обработки

Данные используются только для обратной связи, уточнения задачи, предварительной стоимости и времени визита.

Хранение

Заявки сохраняются на сервере сайта. Доступ к ним должен быть ограничен владельцем сайта или ответственным сотрудником.

Передача третьим лицам

Данные не передаются третьим лицам, кроме случаев, когда это требуется по закону или необходимо для обработки обращения клиента.

Удаление данных

Клиент может запросить удаление своих данных, обратившись по телефону, указанному на сайте.
